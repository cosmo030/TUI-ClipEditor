# TUI-ClipEditor

A terminal video clip editor: open a video, scrub through it with an in-terminal preview, mark the parts you want, and export them as separate clips with ffmpeg.

**Status:** In development · **Tier:** 1 (see [AGENTS.md](AGENTS.md))

Setup and usage instructions are added together with the application code.
